## 安装

### Windows

1. 解压 zip，双击 `短视频去水印_安装包_v1.2.12.exe`
2. 一路下一步，桌面生成图标
3. 打开软件，用**邮箱 + 密码**登录（注册时的账号）
4. 360 / 电脑管家提示风险时选「允许运行」（没做数字签名，只提示一次）

### Mac

1. 解压 zip，把 `短视频去水印.app` 拖进「应用程序」
2. 第一次打开会被拦（未做苹果开发者签名），两种方法都行：
   - 在「应用程序」里**右键点图标 → 打开 → 再点打开**
   - 或打开终端执行：`sudo xattr -cr "/Applications/短视频去水印.app"`
3. 打开后邮箱 + 密码登录

## 怎么用

1. 在抖音/小红书 App 里点「分享 → 复制链接」
2. 粘贴到软件上方输入框（一次最多 50 条）
3. 点「批量提取」→ 等状态变成「等待下载」
4. 点「一键下载全部」

每次下载会在保存目录里生成一个带时间的文件夹：

```
2026-11-18 14-30 任务A1B2C3/
  视频/001_作品标题.mp4
  封面/001.jpg
  图片/002_1.jpg
  文案/001.txt     ← 标题、作者、链接、作品描述
```

## 状态列怎么看

| 状态 | 意思 | 怎么处理 |
|---|---|---|
| 等待下载 / 完成 | 正常 | — |
| 失败·短链 | 分享链接过期了 | 回 App 重新复制分享链接 |
| 失败·不可见 | 作品被删 / 设私密 / 需登录 | 浏览器里点开确认一下 |
| 失败·限流 | 平台限流 | 设置里点「一键获取 Cookie」，或过几分钟再试 |
| 失败·网络 | 网络中断 | 换网络或点「重试失败」 |
| 失败·已取消 | 你点了停止 | 点「重试失败」继续 |
